## I. Leviers transverses (multiplicateurs, pas des business)
- I1 **Holding à l'IS** : réinvestir sans payer l'impôt perso ; apport-cession (150-0 B ter).
- I2 **Effet de levier bancaire** : salaire stable = capacité d'emprunt.
- I3 **Agents IA** pour remplacer l'équipe (support, dev, marketing, compta).
- I4 **Exit planifiée** : construire dès le départ pour revendre (documentation, process, récurrence).
- I5 **Réinvestissement systématique** des flux d'un moteur dans le suivant.
- I6 **Associés / co-investisseurs** pour mutualiser temps et capital.

## Idées « absurdes » (pour élargir, pas pour faire)
Loto, paris sportifs, memecoins, levier ×100 sur crypto. → Espérance négative ou ruine quasi certaine. Écartées dès maintenant sauf avis contraire.

## Premières intuitions (non validées)
1. Les ⭐⭐⭐ ont un point commun : **un actif d'entreprise revendu sur multiple** (SaaS vertical, agents IA, rachat PME, consulting-to-SaaS).
2. Ton profil data / Foundry / produit est un avantage rare → C2, C3, C8, C10, G4 semblent mieux placées que la moyenne.
3. Une architecture « **barbell** » se dessine : socle sûr (A1/B1) + 1 moteur principal (business) + quelques paris (A8, A4).
