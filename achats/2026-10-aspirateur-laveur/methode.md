# Méthode de notation — robot aspirateur laveur (validée le 2026-11-08)

## Principes
- Chaque critère a un **barème fixe** : la même mesure donne toujours la même note.
- Le **niveau de preuve** est affiché à part :
  - 0 = annonce du fabricant seule → « non mesuré », critère retiré du calcul ;
  - 1 = un test à protocole publié (B : Vacuum Wars, The Hook Up, Expert Reviews) ;
  - 2 = deux tests B concordants, ou un test indépendant (A : Rtings, Stiftung Warentest, Que Choisir, Which?, Consumer Reports) ;
  - 3 = enquête indépendante auprès des propriétaires.
- Les avis isolés, blogs affiliés et sites recevant les robots sans protocole publié (C) ne comptent pas. Les étoiles Amazon non plus (avis achetés ou incités).
- Un critère non mesuré est **retiré du calcul** du robot ; on affiche la **couverture** (part des poids réellement mesurée).
- Si deux sources se contredisent : la source A l'emporte sur la B ; entre deux B, on fait la moyenne et on le signale.
- **Prix à part** : il n'entre pas dans le score. Il est affiché à côté, daté, avec un prix cible.
- **Hauteur éliminatoire** : le robot doit passer sous le lit (mesure à fournir).

## Critères, poids et barèmes
| Critère | Poids | Barème |

| Poils et cheveux (ramassés, sans s'emmêler ni boucher) | 25 | Moyenne de : poils ramassés Vacuum Wars (≥ 95 % = 10 ; 90–94 = 8 ; 85–89 = 6 ; 80–84 = 4 ; < 80 = 2) ; enroulement cheveux 18 cm Vacuum Wars (0 % = 10 ; 1–10 % = 7 ; 11–30 % = 4 ; > 30 % = 1) ; verdict Rtings ou Stiftung Warentest (excellent = 10, bon = 8, correct = 6, passable / acceptable = 5, décevant / médiocre = 3, mauvais = 1). Bouchage par les cheveux signalé par une source A ou B : −2. |
| Tapis au sec | 15 | Dépose automatique des serpillières = 10 ; relevage ≥ 20 mm = 7 ; 10–19 mm = 5 ; < 10 mm = 2 (fiche fabricant, acceptée pour une capacité mécanique). −3 si un test A/B a vu un tapis mouillé. |
